# 🎮 Online GameShop Website

Online GameShop Website is a web-based platform built using ASP.NET, designed to help users buy digital games.

## 📂 Project Structure
- **`ISB42403_GroupProject/`** — Main project folder containing the application source code
- **`ISB42403_GroupProject.sln`** — Visual Studio solution file
- **`.gitattributes`** / **`.gitignore`** — Repo configuration files

## 🛠️ Tech Stack
- **Framework:** ASP.NET
- **Language:** C#

## 🚀 Getting Started

### Prerequisites
- Visual Studio (2019 or later recommended)
- .NET Framework installed

### Running the Project
1. Clone the repository
```bash
   git clone https://github.com/MuhammadHuzir/C-Website-Project.git
```
2. Open `ISB42403_GroupProject.sln` in Visual Studio
3. Restore/build the solution
4. Run the project (F5 or Start button in Visual Studio)

## ✨ Features
- Browse and purchase digital games
- User-friendly interface for game discovery
